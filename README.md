# Soupersoop

(she/her)

### Hi! I'm Soupersoop, an indie game dev, music producer, and artist!

I make a wide variety of stuff, including fan-content for various games.
I started off small, making little games on Scratch before I began to expand them into projects that I could be proud to show to the world.\
\
While this GitHub page was made for a college computer science class, I might be updating this thing more should I find myself using GitHub far more often!

## What I'm Doing

Currently, my attention is being juggled by college, Plants vs. Zombies Infected, and a new NES-styled Doom game yet to be publicized, along with some other changes I'm making to a few of my other already existing games.

## Music

The music I make is made in OnlineSequencer.net or LMMS.
I do not have an explicitly defined genre that I stick to.
My work includes heavy metal, chiptune, EDM, ambience, and really whatever else I feel.\
You can find them either on [OnlineSequencer](https://onlinesequencer.net/members/117693?date=1&sort=2) or on YouTube ([links](#useful-links) below)

## Art

The vast majority of my art is made in ibisPaint.
Graphics for my games, however, are commonly made using Scratch's built-in costume editor.\
You can find me on ibisPaint [here.](https://ibispaint.com/artist1/1667590976150577153/)
